The programme unit. Lay several out in a horizontally scrolling rail with `scroll-snap-type: x mandatory`, or set `width="100%"` and drop them into a grid.

```jsx
<FilmCard day="Csütörtök" time="20.00" title="Mamma Mia!" description="Musical a legnagyobb ABBA slágerekkel" venue="Dobó tér" />
```

Times use a dot ("20.00"), never a colon. Descriptions are one sentence with no full stop when they are a fragment.
